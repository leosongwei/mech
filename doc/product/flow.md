# 用户交互流程

## 1. 进入游戏

```
打开 http://<host>:8010/
        │
        ├─ 显示启动页（CONNECTING... / LOADING 16 KM MAP... / READY）
        │     └─ 连接失败：CONNECTION FAILED - IS THE SERVER RUNNING?
        │
        └─ 连接成功 → WebSocket 建立 → 收到一次性初始化包（地图 + 全部数值定义）
              └─ 载入 16 km 地形、生成小地图 → 进入大厅
```

* 客户端打开即连接，不需要账号或注册；身份只由进程内的 pid 决定。
* 启动页同时列出全部键位（见 [screens.md](screens.md#1-启动页--大厅)）。

## 2. 大厅（部署前）

| 项目 | 说明 |
| --- | --- |
| PILOT ID | 呼号，默认 `PILOT-<pid>`，最多 16 字符 |
| SIDE | 选择 RED / BLUE，或 AUTO（自动分配到人数较少的一方） |
| LEFT ARM / RIGHT ARM | 从可购买武器中选择初始双臂武器，下拉项显示名称与射程 |
| 武器说明 | 显示左右臂武器的伤害、射程、射速、是否锁定与一句话描述 |
| DEPLOY | 开始游戏：发送 `join`，服务器在原地生成机甲并请求鼠标指针锁定 |

大厅决定三件事：阵营、呼号、双臂初始武器。部署后仍可在基地或己方城镇购买换装，
但阵营不可更改。

## 3. 对局中的操作循环

```
              ┌──────────────────────── 每秒 30 次 ────────────────────────┐
              │ 鼠标 → 躯干朝向 / 手臂俯仰      滚轮 → 瞄具 1x/4x/10x/20x │
              │ WASD → 移动（相对视角）         ALT+鼠标 → 自由观察         │
              │ 左键 / 右键 → 左臂 / 右臂开火   1-5 / SHIFT+1-5 → 购买左右臂 │
              └──────────────────────────────────────────────────────────────┘
```

1. **移动**：机甲朝视角方向平移，腿自动转向行进方向；背对行进方向时速度下降
   （对齐系数 0.45–1.0）。底盘血量归零后只能以 20% 速度爬行。地形（树、岩石、
   建筑、基地）阻挡通行。
2. **瞄准**：视角即炮口方向。每把直射武器都会在准星位置显示**预测弹着点**与
   距离，预测使用与服务端完全相同的重力与 1/30 s 步进，所以准星即落点。
3. **开火**：左键打左臂，右键打右臂；手臂被打掉后该臂无法开火，准星变暗。
   半自动武器（无制导火箭巢）每次扣扳机只发射一发，按住不放不会连发。
4. **瞄准镜**：滚轮在 1x / 4x / 10x / 20x 之间切换，倍率平滑过渡，视场角随倍率
   收窄，越大的倍率后坐抖动越不明显（按倍率缩放）。
5. **锁定**：装备红外反坦克导弹时，把准星保持在一辆敌车上 1.1 s，锁定框收缩到
   中心变红并发出稳定提示音，此时开火即发射，导弹自动爬升俯冲；未锁定开火无效，
   HUD 提示 `NO LOCK`。
6. **购买**：只有在己方指挥部或己方城镇 220 m 内才会出现 `AT BASE - REARM:` 清单。
   按 `1`–`5` 为左臂、`SHIFT`+`1`–`5` 为右臂购买，条件：在补给范围内且金钱足够。
   换装立即生效并补满弹药。

## 4. 受伤、死亡与重生

```
命中 → 对应模块扣血（溅射会挑最近的一个部位）
  ├─ 手臂血量 0 → 该臂武器报废（弹药清零，HUD 显示 DESTROYED）
  └─ 躯干或底盘血量 0 → 机甲爆炸
        └─ MECH DESTROYED + 死亡镜头（绕己方基地环绕）
              └─ 8 s 倒计时 → RE-DEPLOYED
                    └─ 出生点：己方最靠前的已占领城镇（离敌方基地 > 900 m 时），
                       否则己方指挥部 70–130 m 环内
```

* 死亡不扣钱、不掉武器；换装保留。
* 死亡期间相机自动环绕己方指挥部，仍可看战场。
* 击杀敌方单位获得赏金（见 [units.md](units.md)），敌方基地被摧毁的瞬间本局结束。

## 5. 经济

| 来源 | 数值 |
| --- | --- |
| 初始资金 | $600 |
| 被动收入 | $4 / s（双方玩家相同） |
| 击杀赏金 | 步枪兵 $45、反坦克兵 $70、APC $180、AI 机甲 $350、指挥部 $2000 |
| 消费 | 购买武器（$180–$700，见 [weapons.md](weapons.md)） |

金钱只用于换装，死亡与失败不惩罚资金。

## 6. 城镇占领

1. 城镇以 `170 m` 为占领半径，场上只有一方战斗单位且持续 `9 s`，该方占领。
2. 双方单位同时在半径内时进度冻结并以 `0.5/s` 回退。
3. 占领成功：小地图方块变为己方颜色，HUD 提示 `TOWN SECURED` / 敌方视角
   `TOWN LOST`；该城镇成为己方前线出生点（购买补给也延伸到该城镇 220 m 内）。
4. 开局双方各自持有离自己指挥部最近的 3 座城镇。

## 7. 波次与 AI 增援

* 每 `22 s` 一波（首波在开局 8 s 后），双方各三条路各出一批。
* 每批编成：4 名步枪兵 + 1 名反坦克兵；每第 3 波追加 1 辆 APC；每第 4 波
  追加 1 台 AI 机甲。
* 空投点：该路"前线"（己方最靠前的单位）往后 10 个路点，再在 20–90 m 半径内
  找一块空地；没有前线时改用城镇/基地出生环。单方战斗单位上限 120。
* AI 行为：沿路推进，每 0.45 s 搜一次目标（有视线才锁定），进入射程后停车开火，
  目标太远或绕不过去就继续推进；炮塔独立转向（APC 2.2 rad/s，其余 3.2 rad/s）。

## 8. 胜负与重开

```
敌方指挥部（6500 HP）被打爆
        │
        ├─ 全屏 VICTORY / DEFEAT + `ENEMY COMMAND BASE DESTROYED`
        │
        └─ 40 s 倒计时（NEW MATCH IN n s）
              └─ 同一张地图重开：清空战场、重建基地/城镇/平民，
                 双方玩家 3 s 后在各自基地区域重生，金钱、击杀与死亡数保留
```

平局不存在：先打爆对方指挥部的一方获胜。

## 9. 调试流程（仅当服务端 `MECH_DEBUG=1`）

* 界面右上角出现 **DEBUG** 面板，三个按钮：`RESPAWN`（跳过死亡倒计时）、
  `RESTART`（清场重开一局）、`GOD ON/OFF`（免疫伤害，按钮高亮表示开启）。
* 控制台可用调试消息：`debug_spawn`（在面前生成单位）、`debug_tp`（瞬移）、
  `debug_hurt`（自伤或打敌方指挥部）、`debug_god`、`debug_restart`。
* 指针被锁定时按钮点不到，需先按 `ESC` 释放鼠标（或直接把指针移出画面）。
* 调试功能不影响正式玩法；`MECH_DEBUG` 关闭时面板与这些消息全部消失/被忽略。
