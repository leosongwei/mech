# 用户交互流程

## 1. 进入游戏

```
打开 http://<host>:8010/
        │
        ├─ 显示启动页（CONNECTING... / LOADING 16 KM MAP... / READY）
        │     └─ 连接失败：CONNECTION FAILED - IS THE SERVER RUNNING?
        │
        └─ 连接成功 → WebSocket 建立 → 收到一次性初始化包（地图 + 全部数值定义）
              └─ 载入 16 km 地形、生成小地图 → 进入大厅
```

* 客户端打开即连接，不需要账号或注册；身份只由进程内的 pid 决定。
* 启动页同时列出全部键位（见 [screens.md](screens.md#1-启动页--大厅)）。

## 2. 大厅（部署前）

| 项目 | 说明 |
| --- | --- |
| PILOT ID | 呼号，默认 `PILOT-<pid>`，最多 16 字符；**存在浏览器里**（`localStorage: mech.name`），刷新页面后预填上次用的呼号 |
| SIDE | 选择 RED / BLUE，或 AUTO（自动分配到人数较少的一方） |
| DEPLOY | 开始游戏：发送 `join`，服务器生成机甲并请求鼠标指针锁定 |

呼号一经部署就写进浏览器，重开页面时自动填回（`PILOT ID` 一栏可以直接改）。
大厅只决定两件事：**阵营与呼号**。机甲**一律以默认装备出生**（左臂 30mm 机炮 +
右臂无制导火箭巢），大厅里**没有武器选择**——换装是基地/城镇里的 `B` 面板买卖，
不是出生前的菜单。部署后阵营不可更改。`DEPLOY` 只算一次：进入游戏后**再按
`ENTER` 不会再出生一次**（按钮在部署时交还焦点）。

## 3. 对局中的操作循环

```
              ┌──────────────────────── 每秒 30 次 ────────────────────────┐
              │ 鼠标 → 观瞄（车身/俯仰随后追）  滚轮 → 瞄具 1x/4x/10x/20x │
              │ CTRL+滚轮 → 调零距离 0.5–4 km（500 m 一档）              │
              │ WASD → 移动（相对视角）         ALT+鼠标 → 自由观察         │
              │ 左键 / 右键 → 左臂 / 右臂开火   B → 换装面板   ENTER/ESC → 确认/取消 │
              └──────────────────────────────────────────────────────────────┘
```

1. **移动**：机甲朝视角方向平移，腿自动转向行进方向；带有**加速度**——车身以
   9.3 m/s² 逼近指令速度（最高 180 km/h，0–100 km/h 约 3 s），背对行进方向时
   速度下降（对齐系数 0.45–1.0）。机体血量归零即爆炸，没有"残血爬行"这一档。
   地形（岩石、建筑、基地）整格阻挡通行；**树只有树干挡路**，树冠不挡车，可以开进
   树林从树干之间穿过去。撞上任何实体都会被挡住并清零速度。
2. **瞄准**：**视角只转观瞄，不转炮口**。车顶观瞄塔的镜头瞬间跟随鼠标，车身以
   **80°/s**、两臂俯仰以 **50°/s** 追上去，所以快速甩视角时中心叉先到、炮管后到，
   左右臂的**预测弹着点**会明显落后于中心叉，转到位才并上来。每个弹着点预测使用与
   服务端完全相同的重力与 1/30 s 步进，且按**该臂炮管的实际朝向**算，所以标记在哪
   弹就落在哪。观瞄塔的轴心不在车身回转轴心上（后 0.62 m），车身追赶时眼点会随车身
   在圆弧上平移。
3. **开火**：左键打左臂，右键打右臂；手臂被打掉后该臂无法开火，准星变暗。
   半自动武器（无制导火箭巢）每次扣扳机只发射一发，按住不放不会连发。
4. **瞄准镜与调零**：滚轮在 1x / 4x / 10x / 20x 之间切换，倍率平滑过渡，视场角随
   倍率收窄，越大的倍率后坐抖动越不明显（按倍率缩放）。**CTRL+滚轮**调**调零距离**
   （0.5 / 1 / 1.5 … 4 km，500 m 一档，默认 1 km，显示在 `OPTICS` 下面那行 `ZERO`）：
   炮口按这个距离抬起固定的角度，弹道在该距离上与中央的中心叉相交。所以近距离的敌车
   要往下打（左右臂准星会落在中心叉下方），远距离要往上——**准星读数就是干这个用的**。
5. **锁定**：红外导引头装在观瞄塔上，**跟着视角瞬时转**（不等车身）。装备红外
   反坦克导弹时，把准星保持在一辆敌车上 0.6 s，锁定框收缩到
   中心变红并发出稳定提示音，此时开火即发射，导弹自动爬升俯冲；未锁定开火无效，
   HUD 提示 `NO LOCK`。导引头**要看得到车**：被山体、建筑或树林挡住的敌车锁不上
   （准星圈扫过去不会收缩），锁定中的车开进掩体后面**立即脱锁**。
6. **热烟幕**：按 `Q` 抛出 **14 发烟弹**，**炸点固定在前方 50 m**，飞行时间
   **±20%**（0.9–1.4 s 后炸开），炸开成半径 **45 m 上下（±20%**：36–54 m）的实心
   烟球（炸开时先快后慢地扩散），十几个叠起来**盖满正半球**（平视、抬头都是烟），
   维持 **5 s**。每发烟弹的飞行时间和烟球大小各自随机，所以烟幕边缘是毛的、不是
   整齐的格栅。每命 **10 次**烟幕，两次之间冷却 **0.5 s**，重生补满；在基地/城镇
   可花 $250 补一次（换装面板 `REARM SMOKE`，库存已满 10 次，所以买的是
   **冷却清零**）。
   烟幕会**吃掉来袭的红外攻顶导弹的锁定**（导弹转惯性），并让 AI **失去目标、转为
   朝最后位置射击** 4 s。地形和建筑同理：来袭导弹的导引头被山或楼挡住就断锁转惯性。剩余次数与冷却显示在右上角告警圈下方（`SMOKE 10 [Q]`）。
7. **告警圈**（右上角，圈的正上方是机体朝向，圈的外沿是本机的**发现距离**：机甲
   1.0 km、APC 500 m）：中心绿点是自身。自卫雷达只有一条判据——多普勒回波
   `radar_strength · RCS / d⁴ · (v_closing / 600)² ≥ 1`，所以**只有正在接近**的导弹
   与火箭有回波（子弹一概没有），距离表见 [weapons.md](weapons.md)。

   **只报 1 km 以内**（本机发现距离比 1 km 还短时按本机，比如 APC 500 m），并且
   **要求视线通畅**：山体、建筑、树冠、烟幕挡住的弹告警器收不到——和 AI 的瞭望、
   红外锁定、预瞄框走的是同一条视线规则。

   **圈上显示 ≠ 响警报**：
   * **红色菱形**＝已探测：真实方位、真实距离，**不管是不是冲着自己来的**。同时
     世界里那发弹上出现**白色预瞄框**（同样只在本机视线通畅时画），可以顺手打掉；
   * **圈边到圆心的红线，5 Hz 闪**＝未探测但正在逼近：只知道方位，没有距离；
   * **警报音只在“这发弹打得到我”时才响**：来袭方向按**导弹速度与自机速度的相对
     矢量**解算（迎着弹跑更早亮、背着跑更晚，横穿的不算），要求最近接近点在弹的
     杀伤半径内（`er + 20 m`，20 m 是装甲的减免档）；制导弹（SACLOS / 攻顶）因为
     飞的是航路不是直线（攻顶弹要爬到 150 m 再砸下来），按**水平航迹**判。圈沿变红
     也只在有“打得到我”的弹时；只是被扫到的弹，圈沿保持常色；
   * **菱形消失**＝弹飞过去 / 被甩开 / 被击落（击落处有一小簇火花，**没有任何提示
     音**——战斗里 AI 机组满地图拦弹，一个音一个响会把耳朵占满）。

   **红色短线**是激光告警（有 AI 或敌方玩家的视线压在自己身上时）标出的来向。
   两者各有独立警报音，都取自 AN/ALR-67 RWR：导弹是 0.083 s 换一次音的快速颤音
   （循环到威胁消失），激光是同一对音 0.25 s 换一次的慢速摆动（视线在就响）。
8. **换装 / 维修**：只有在己方指挥部或己方城镇 220 m 内才能补货，此时左下出现
   黄字 `[B] REARM / REPAIR`。按 `B` 打开面板：左右臂各有一个武器下拉框
   （列出 5 种武器、满装价格与 `本体 + 弹药` 明细）、各自的 `REARM` 补弹按钮，
   中间是 `REPAIR` 修机（从零修满 $400），上方是 `REARM SMOKE`（$250）。
   所有改动先在 `CHANGES` 里逐行报价（右侧同时给出**这一笔要花的时间**）、
   最后给 `TOTAL + 总时间`，按 `CONFIRM (ENTER)` 一次性成交，`CANCEL (ESC)`
   全部作废。旧武器按 **50% 回收、再乘该臂剩余血量**折价，所以被打残的手臂
   换装最亏。钱不够时 `CONFIRM` 变灰、整单不扣钱。
   **成交不是立刻生效**：换掉一侧武器 **2 s**、补满一侧弹药 **4 s**、维修
   **每 100 HP 2 s**（烟幕当场给），几项相加（把 30mm 机炮换成机枪 = 2 s + 4 s
   = 6 s）。开工后画面中下部出现**进度条**，整备期间机甲**不能移动、不能开火**
   （视线可转），进度走完武器/弹药/装甲才真正到位——所以守在城镇里补血补弹
   给了对手 4 秒、6 秒的真实窗口，而不是瞬间满状态重返战场。
   面板右下角还有一个 **`REPAIR & REARM` 一键按钮**：不用点草稿，直接把两台
   手臂的弹药补满、所有部位修满，按钮上写着预计金额与时间（钱不够时变灰）。

## 4. 受伤、死亡与重生

```
命中 → 穿透伤害 + 爆炸伤害（溅射只算爆炸，且挑最近的一个部位）
  ├─ 手臂血量 0 → 该臂武器报废（弹药清零，HUD 显示 DESTROYED）
  └─ 机体血量池（底盘 + 躯干）0 → 机甲爆炸
        └─ MECH DESTROYED + 死亡镜头（绕己方基地环绕）
              └─ 3–40 s 倒计时（按死亡地点算）→ RE-DEPLOYED
                    └─ 出生点：见下面的 A → B → C 三步，找不到则己方指挥部
                       70–130 m 环内
```

**重生点：三步选城（允许跨兵线）**。阵亡时按下面三步算出生城镇，找不到就回基地：

1. **A**：己方控制的城镇里，**离阵亡地点最近的一座**（这一步只用来确定"看哪条
   兵线"，跨不跨线都行）。
2. **B**：在 A 所在的那条兵线上，取**离阵亡地点最近、且与己方指挥部连通、且没有
   在争夺**的那座（A 自己满足条件就是 A）。
3. **C**：从 B 沿这条兵线**朝己方基地退一座**——C 就是出生点；B 已经是兵线上最靠
   基地的一座时没有 C，回基地。

所以"死在城边"永远会出生**身后一座城**，被敌人截断的城、正在挨打的城都不会被选中，
而安全的后方城即使不在这条线上也可以出生。以
`红基地 - 红1 - 红2 - 红3 - 蓝(被截断) - 红4 - 红5` 为例：

| 阵亡位置 | A | B | 重生在 C |
| --- | --- | --- | --- |
| 红1 附近 | 红1 | 红1 | **红基地**（红1 是最靠基地的一座） |
| 红2 附近 | 红2 | 红2 | 红1 |
| 红3 附近 | 红3 | 红3 | 红2 |
| 红4 附近 | 红4 | 红3（红4 被蓝城截断） | 红2 |
| 红5 附近 | 红5 | 红3 | 红2 |

刚部署（第一次出生）不走这条规则：出生在**离敌方指挥部最近的、仍与己方连通的
非争夺城镇**（若它已在敌方基地 900 m 内，则改为指挥部环内），省得开局先跑 5 km。

**重生等待：离家越远越快。** 倒计时按**被击杀地点到敌方指挥部的距离**线性插值：
在己方指挥部边上阵亡等 **40 s**，在敌方指挥部边上阵亡只等 **3 s**，中间按比例
（半程约 21 s）。也就是说越往前打，被打掉后的空窗期越短，越是在自家门口被偷袭，
惩罚越重。

* 死亡不扣钱，但**装备随车一起没了**：重生出来的是一台标准机体（左臂 30mm 机炮 +
  右臂无制导火箭巢，`defs.DEFAULT_LOADOUT`），花 $800 买的 105mm 打完那一局就没了，
  想再带得回基地/城镇重新买一次。被击毁的步兵留下尸体 5 s，车辆/机甲留下冒烟
  的暗色残骸 10 s（纯视觉，见 [units.md](units.md#残骸)）——不过**机甲和装甲车死的
  那一刻会自爆**：爆心在车自己身上，**ER 30 m / ED 10**，不分敌我，周围的
  单位同样挨炸（见 [weapons.md](weapons.md#阵亡爆炸apc--机甲自爆)）。
* 死亡期间相机自动环绕己方指挥部，仍可看战场。
* 击杀敌方单位获得赏金（见 [units.md](units.md)），敌方基地被摧毁的瞬间本局结束。

## 6. 城镇占领

**城镇的样子**：每座城镇都是**沿兵线长出来的街区**——几十条互相接通的**街道**
（丁字路口、十字路口、闭合成圈的都有，**几乎没有死胡同**），街道两侧**成排的楼房**
（一行 2–5 栋贴着盖），排与排之间留出空地/院子，所以街道两边是敞开的、能一眼看到
街对面。**每座城镇最多 200 栋楼**（随机 120–200 栋），占地 **约 300–650 m 见方**，
越靠中心楼越高（市中心 **4–8 层（16–32 m）**，中圈 3–6 层，外围 2–4 层）。城镇正中
的**广场**是空的：兵线从广场正中笔直穿过，广场半径约 **80 m**，前线城镇的出生点
（城镇外 **40–70 m** 环）就落在这里，平民也在这里走。每座城镇的街区宽度、街道
走向、占地范围和楼高分布都各自随机，所以**没有两座城镇长得一样**。兵线本身永远是
直的、通行的：路边留出一条（斜路留两条）空地块，**没有任何楼房压在兵线上**。

**街上不会走不出去**：随机长出来的街道会留下断头路和"两边都下不去"的长街，所以
生长结束之后还要过两道工序——①**每 4 格在长街上打通一条横街**（通到隔壁那条街，
只有对面真有街才打，不会凭空造死胡同）；②**逐条把断头路接出去**（朝着最近的另一
条街铺最短的一条通道、绕开楼房，直到闭成一个圈）。结果：直街在两个路口之间的
平均长度只有 **2 格**（1% 超过 6 格），断头路只剩 **0.1%** 的街道格，单座城镇的
街道网络**连成一片**（25 座里 24 座只有一份）。

1. 城镇以 `170 m` 为占领半径，场上只有一方战斗单位且持续 `9 s`，该方占领。
2. 双方单位同时在半径内时进度冻结并以 `0.5/s` 回退。
3. 占领成功：小地图方块变为己方颜色，HUD 提示 `TOWN SECURED` / 敌方视角
   `TOWN LOST`；该城镇成为己方前线出生点与补给点（购买补给延伸到该城镇 220 m 内）。
4. **争夺中的城镇不出兵**：半径里有非持有一方的战斗单位时，这座城在刷兵规则里
   暂时失效，兵从它身后那座城出（见下一节）。
5. 开局双方各自持有离自己指挥部最近的 3 座城镇。

## 7. 增援：指挥部机甲与城镇驻军

**刷兵点：每条兵线只有一座城镇**——从己方指挥部沿兵线往前数，**仍然与指挥部
连通的最靠前的那座**（`基地 - 蓝1 - 蓝2 - 红 - 蓝3` 里是 `蓝2`，红城和它之后的
`蓝3` 都不刷）。被截断时前线自动后退一座，重新占领断点后前线再前推。
中立城镇同样算截断。

**正在挨打的城镇不刷兵**：按上面的规则本该在 `红3` 出兵时，只要它的 `170 m` 圈里
站着不属于红方的战斗单位，这个刷兵点就暂时失效，兵改从**它身后那座城**出
（`红基地 - 红1 - 红2 - 红3(争夺) - 蓝1` → 从 `红2` 出）；身后那座也在打，就继续
往后退，一路退到没有可用的城为止（这条兵线这一波就不出人，指挥部机甲不受影响）。
所以贴脸冲锋一次，能立刻掐掉对方一条兵线的兵源，而不必真的把城打下来。

| 来源 | 间隔 | 产出 |
| --- | --- | --- |
| 指挥部 | **120 s**（首波在开局 8 s 后） | **3 台机甲**，三条兵线各一台，出现在指挥部外 70–130 m 环 |
| 前线城镇 | **60 s** | 一队步兵：**6 名反坦克兵 + 4 名步枪兵** |
| 前线城镇 | **60 s** | **1 辆 APC** |

* 刷出的兵沿**该城镇所在的兵线**向敌方推进（步兵/车辆走兵线路点，机甲同理）。
* 每条兵线只有一个刷兵点，所以一方最多同时有 3 座城镇在出兵（三条线各一座）。
* 只有当前线的城镇才走计时器；前线后退时新前线接着用它自己剩下的时间。
* AI 行为：沿路推进，每 0.45 s 搜一次目标（有视线才锁定），进入射程后停车开火，
  目标太远或绕不过去就继续推进；炮塔独立转向（APC 2.2 rad/s，其余 3.2 rad/s）。
  唯一的例外是**敌后破袭机甲**：它有自己的一条路线（见下）。

### 敌后破袭机甲（raider）

光靠沿兵线推，胜负只取决于谁喂前线喂得快。所以双方指挥部**各自每 120 s 派出
2 台破袭机甲**（开局 60 s 首发，两侧错开 10 s，同一方最多同时 6 台在场）。它们
**不走兵线**，而是穿过原野绕到敌人后方，专门去**切断补给链**——按上面的规则，
一条兵线上只要有一座城被对方拿走，它后面的城镇就不再出兵。

* **任务：随机两条兵线，各一台**。每次出发时从 3 条兵线里**随机抽 2 条**（不重复），
  一台负责一条，**各自单独规划**——两台不去同一座城，敌人没法蹲一个点就把整队堵死。
* **打哪座城：本兵线上敌人防守最弱的一座**。系统维护一张**势力梯度图**：敌方每个
  会开火的战斗单位，按**它自己的视野半径**、随距离线性衰减、按威胁加权（机甲 3、
  APC 2、反坦克兵 1、步枪兵 0.5）铺在地图上，读数就是"站在这块地上会被多少火力
  看到"。取该兵线上梯度最低的敌方城镇，另加**每公里行军 0.15** 的轻微距离惩罚，
  免得为省一个守军横穿全图。该兵线已无敌方城镇时，改打**任意兵线上最弱的一座**；
  敌人一座城都不剩时，直接去打敌方指挥部。
* **怎么走：两级寻路**。先在 **128 m 战略网格**上跑加权 A*，成本 = 地形
  （树林 ×8、楼房 ×8）+ **势力梯度**（每单位 +0.35，上限 12）——所以路线会**绕开
  敌军主力，也绕开树林**，从敌人防线上最薄的地方穿过去；离目标城镇 400 m 时交接到
  **16 m 街道网格**，按真实街区（楼房是墙、街道是路）规划最后一段，机甲不会顶在
  房子上。被地形卡住时会用街道网格做**局部改道**（2 s 冷却），整条路线重规划冷却 12 s。
* **占领与固守**：进入 170 m 占领圈并停留 9 s 即占领（规则同普通城镇），该兵线的
  补给链当场被切断；占领后机甲**在圈内固守 90 s**——圈里只要有己方战斗单位，敌人
  就无法反占领——然后再转向本兵线下一个最弱的敌方城镇，如此循环。
* **代价**：破袭机甲就是普通机甲（100 血、双臂各 50、赏金 $350），没有额外护甲、
  没有额外补给、小地图上与普通敌方机甲没有区别。被切断补给的敌人会从新的前线城镇
  刷兵反扑，所以得手之后常被围歼：实测一局 12 分钟（种子 11）出发 24 台、拿下城镇
  5 台、固守 3 台、**被击毁 14 台（58%）**。
* 战斗行为不变：搜敌、提前量、开火仍走同一套 AI（每 0.45 s 搜一次、有视线才锁定），
  只是行军由任务接管——遇到敌人它会边打边走，不会绕过去装看不见。

## 8. 胜负与重开

```
敌方指挥部（4000 HP）被打爆
        │
        ├─ 全屏 VICTORY / DEFEAT + `ENEMY COMMAND BASE DESTROYED`
        │
        └─ 40 s 倒计时（NEW MATCH IN n s）
              └─ 同一张地图重开：清空战场、重建基地/城镇/平民，
                 双方玩家 3 s 后在各自基地区域重生，金钱、击杀与死亡数保留
```

平局不存在：先打爆对方指挥部的一方获胜。

## 9. 设置与调试流程

```
按 ESC 释放鼠标 → 点右上角齿轮（告警圈左侧一列）→ SETTINGS 面板
                                   ├─ SOUND：MASTER 主音量 / ALARM 告警器音量
                                   └─ DEBUG：RESPAWN / RESTART / GOD（仅 MECH_DEBUG=1）
                                         └─ 关闭：× / CLOSE / ESC → 鼠标重新锁定
```

* **设置菜单**对所有人开放：`SOUND` 两行滑条——`MASTER` 主音量 0–100%，默认 50%
  （此默认值下整体响度是旧版的三倍）；`ALARM` 只管导弹 / 激光告警音，默认 50%
  （= 旧版响度）。改动存在本地，刷新后保持。
* **DEBUG 区块**只在服务端 `MECH_DEBUG=1` 时出现，三个按钮：`RESPAWN`（跳过死亡
  倒计时）、`RESTART`（清场重开一局）、`GOD ON/OFF`（免疫伤害，按钮描边高亮表示
  开启）。
* 齿轮需要**自由鼠标**才能点：指针被锁定在座舱里时先按 `ESC`（这也是唯一入口，
  没有键盘快捷键）。
* 控制台可用调试消息：`debug_spawn`（在面前生成单位）、`debug_tp`（瞬移）、
  `debug_hurt`（自伤或打敌方指挥部）、`debug_god`、`debug_restart`，
  以及随时可用的 `respawn`（跳过死亡倒计时）。
* 调试功能不影响正式玩法；`MECH_DEBUG` 关闭时 DEBUG 区块与这些消息全部消失/被忽略。

## 10. 靶场流程（服务器以 `--range` 启动）

靶场是同一套客户端接入的另一张地图，流程与战斗模式相比大幅简化，细节见
[range.md](range.md)。

```
打开 http://<host>:8011/（./dev.sh range 启动）
        │
        ├─ 启动页副标题：WEAPON RANGE · 4 KM MAP · APC TARGETS · REARM ANYWHERE
        │     状态行：CONNECTING... → LOADING RANGE... → READY
        │
        └─ 大厅：呼号与双臂武器照旧，SIDE 选择被忽略（固定 RED）
              └─ DEPLOY → 在南部蓝叉出生，面朝 200 m 山峰
                    ├─ 12 辆被动 APC 靶（10 静止 + 2 巡逻），击毁 3 s 后在随机位置重生
                    ├─ 随处换装：B 面板常驻（买装备只走面板）
                    └─ 无波次、无城镇占领、无胜负判定
```

* 初始资金 `$99999`，`$4/s` 收入照旧；击毁靶子仍得 `$180` 赏金。
* 死亡后 8 s 回到同一个出生点；调试面板 `RESTART` 会重建全部靶子并在 1 s 后
  让玩家重生。
