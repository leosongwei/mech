# 界面说明

界面分两层：DOM（启动页/大厅、右上角调试面板）与 Canvas（HUD 与 3D 场景）。
所有 HUD 文字为英文；本文档用中文描述，引号内保留界面原文。

## 1. 启动页 / 大厅

单页 DOM，铺满窗口。

| 区块 | 内容 |
| --- | --- |
| 标题 | `MECH`（大字、绿色发光） |
| 副标题 | `16 KM SQUARE FRONT · RED VS BLUE · THREE LANES` |
| 键位表 | 两列：`W A S D` 移动、`MOUSE` 躯干/俯仰、`WHEEL` 瞄具、`ALT + MOUSE` 自由观察、`LMB / RMB` 左右臂、`1-5 / SHIFT+1-5` 购买、`ESC` 释放鼠标 |
| PILOT ID | 文本框，默认 `PILOT-<pid>`，最多 16 字符，自动全选 |
| SIDE | 三个按钮 `RED` / `BLUE` / `AUTO`，选中的按钮填色（红/蓝/绿） |
| LEFT ARM / RIGHT ARM | 下拉框，列出可购买武器：`名称  射程km` |
| 武器说明 | 两行文本：`L 名称: 伤害, 射程, 射速[, lock-on] - 描述` |
| DEPLOY | 绿色主按钮；点击后进入游戏并请求指针锁定 |
| 状态行 | 连接进度：`CONNECTING...` → `LOADING 16 KM MAP...` → `READY`；靶场服务器为 `LOADING RANGE...` |
| 错误行 | 左下角红字：启动异常（`BOOT ERROR:`）、运行时错误（`ERROR:`）、未处理拒绝（`REJECT:`） |

靶场服务器（`--range`）下副标题改为
`WEAPON RANGE · 4 KM MAP · APC TARGETS · REARM ANYWHERE`，大厅其余部分不变，
但 SIDE 选择被忽略（固定红方），见 [range.md](range.md)。

连接失败时状态行显示 `CONNECTION FAILED - IS THE SERVER RUNNING?`，DEPLOY 无效。

## 2. 对局 HUD（Canvas 覆盖层）

坐标基于 CSS 像素，随窗口缩放。分为下列区块：

### 2.1 小地图（左上，210×210）

* 地形缩略图（草原/道路/建筑/树林/岩石/基地），边框半透明绿线。
* 城镇：小方块，颜色=持有方（紫=中立），占领进度以白色圆弧表示。
* 单位：方块点，颜色=阵营；机甲点更大；指挥部为白色大方块；平民不显示。
* 自己：绿色圆点 + 一条白色短线指向当前躯干朝向。

### 2.2 顶部战况条（居中）

```
WAVE 12
6:34
ALLIED BASE  ▇▇▇▇▇▇▇░░
ENEMY BASE   ▇▇▇▇░░░░░░
```

* `WAVE n`：当前波次；下一行为本局时长 `m:ss`。
* 靶场模式下首行改为 `RANGE`，并在时长下方多一行 `TARGETS n`（当前存活的蓝方
  单位数，正常为 12 个 APC 靶）。
* 两条 150×5 的指挥部完整度条，按 `当前HP / 6500` 填充，颜色为阵营色，
  上方标签为本方 `ALLIED BASE` / 敌方 `ENEMY BASE`。靶场没有指挥部，两条不显示。

### 2.3 资金与战绩（左侧，小地图下方）

* `$1234`：当前资金（大字）。
* `KILLS n   DEATHS n   SCORE n`：个人战绩，SCORE 为赏金累计。
* 其下为所有玩家的名字与 `击杀/死亡`，按颜色区分阵营。
* 在补给范围内时追加一行黄字 `[B] REARM / REPAIR`，按 `B` 打开换装面板
  （见 2.12）。靶场模式下这行常驻（随处可换装）。

### 2.4 模块状态（左下）

最上方一条 **168×20 的速度条**：左边 `SPEED`，右边当前地面速度，如 `83 km/h`
（超过 150 km/h 时数字与进度条变青色）；底部 3 px 细条按 `速度 / 180 km/h` 填充。
速度取的是**实测位移**（快照间位置差），所以能看到 0–180 的爬升过程。

其下四条 168×15 的血条：`CHASSIS` / `TORSO` / `L.ARM` / `R.ARM`，右上角显示整数血量。
颜色随比例变化：>60% 绿、>30% 黄、其余红。

### 2.5 武器面板（底部居中，左右各一块 250×56）

| 位置 | 内容 |
| --- | --- |
| 标题行 | `L-ARM 武器名` / `R-ARM 武器名`，青色 / 橙色；手臂被毁时显示 `DESTROYED` 并整体变暗 |
| 弹药行 | `弹匣 / 备弹`；无备弹武器（火箭巢）只显示单一数字 |
| 状态 | 换弹中显示黄字 `RELOADING` |
| 脚注 | `x.xkm  一句话描述` |

### 2.6 瞄具指示（武器面板上方）

`OPTICS` 标签 + 四格 `1x 4x 10x 20x`，当前档位高亮（青框）。倍率切换过程中
额外显示实时倍率，如 `7.3x`。

### 2.7 准星（画面中央，双臂各一个）

* 直射/火箭手臂是十字括号准星（左臂青色、右臂橙色），中心一个小点。
* 括号右侧文本：`L 842m`，距离为预测弹着点距离；射线未命中任何单位/地形时显示 `-`。
* 命中单位时中心多一个小圆点。
* 手臂被毁的准星整体变淡（25% 不透明度）。

### 2.8 预瞄：目标白框与预判圈（自动，无需按键）

* 满足条件的敌方车辆（APC、机甲）会自动获得预瞄显示，条件是：**在视口内**、
  **距离 ≤ 4 km**（调零范围）、**屏幕上够大**——车体轮廓不小于**视野高度的 3%**。
  同一时刻最多显示**最近的 4 个**目标，其余不画。
* **白框**：按车体半径与高度投影出的一个白色矩形，框住目标**当前**所在位置，
  随时间跟车移动。这是"已识别"的标记。
* **预判圈**：**每只手一个圆圈**（半径 7 px，颜色仍是左青右橙），画在该臂弹丸
  **将要命中的位置**上——把准星压到圈里就能打中移动的目标。
* **连线**：从白框边缘到圆圈一条同色细线，长度直观地表示提前量。
* 两只手武器不同时两个圈**分得很开**：机炮的弹丸快，火箭巢的慢得多（3.2 km 上飞行
  2.96 s 对 5.68 s，15 m/s 的目标要提前 44 m 对 85 m），所以左右手各自解算；两只手
  装同一种武器时两圈重合。
* **不画圈的情况**：该手是制导武器（SACLOS ATGM、TOP-ATTACK IR ATGM——导弹自己
  追目标，不需要提前量）、该手模块被毁、或者解算失败（仰角超出上限）。
* 移动目标的速度取**服务器快照实测的位移速度**（指令速度在机甲侧移时偏高），
  未来位置的高度取该处**地形高度**，所以上坡下坡时的框会跟着地形起伏。
* 不做遮挡检查：框可能落在被山脊挡住的点上，这时真开火弹丸会打在近处地形上。

### 2.9 告警圈（右上角，半径 78 px = 1 km）

以机体为参考系（圈的正上方 = 机体朝向，随躯干转动）：

| 元素 | 含义 |
| --- | --- |
| 中心绿点 | 自身 |
| 红色菱形（竖起的正方形） | 自卫雷达探测到的**来袭导弹**，按 `距离 / 1 km` 落在圈内 |
| 红色短线 | **激光告警**：有 AI / 敌方玩家的视线压在自己身上，短线指向来向 |
| 圈下一行文字 | 烟幕库存：`SMOKE 10 [Q]`，用光后显示冷却剩余秒数（如 `SMOKE 12s`） |

* 自卫雷达的判据：敌方**非子弹**弹丸、距离 ≤ 1 km、且**正在接近**（沿速度方向的
  接近率为正）。无制导火箭再加两条：速度 ≥ 100 m/s、直线外推会穿过自身 **100 m**
  球体。**SACLOS / 攻顶导弹**只看接近率——攻顶弹会爬到目标上方 150 m 再扎下来，
  直线外推永远擦不到那个 100 m 球体，按老判据只有最后 1 s 才报警。它只判断
  "有高速东西正冲我来"，不预判是否真的会命中。
* 激光告警：敌方步兵 / APC / 机甲（炮塔朝向优先）的视线与自身夹角 ≤ 3°、距离
  ≤ 3.4 km 时点亮，与对方是否真的开火无关。
* 有导弹接近时圆圈边框变红；**两种告警音不同**，都取自 DCS 的 AN/ALR-67 RWR
  告警音（同一对音 426 / 561 Hz、方波味、两音之间无空隙，只有交替快慢不同）：
  **导弹告警**是 0.083 s 换一次音的高速颤音，**循环播放**直到威胁消失，不随距离
  变化（远近看圈里的菱形）；**激光告警**是同一对音 **0.25 s** 换一次的慢速摆动，
  视线压在身上的整段时间里持续响，视线离开后 0.45 s 停。
* 浏览器不给自动播放权限：音频上下文要**用户手势**才能启动，所以页面在
  `DEPLOY`（真点击）或任意一次点击/按键之后才会出声。
* 圆圈整体透明度低，不与右上角消息区重叠（圆心 y = 250 px）。

### 2.10 红外导引头圆圈（装备 TOP-ATTACK IR ATGM 时）

* 该臂的准星换成一个**圆圈**：直径 = 视口宽度 5%（1600 px 宽约 80 px），
  比普通十字准星大一圈；圆圈就是导引头的锁定范围。
* 圆圈**始终是该臂的颜色**（左臂青、右臂橙），锁定状态靠粗细和图形区分，
  不改色：锁定时进度弧跑满一整圈、线宽加到 3.2 px，中心出现同色菱形。
* 锁定中：沿圆周按进度画一段同色弧线，右侧文本 `L 1234m` / `R 1234m`。
* **双手都装导弹**时两个圈**一样大**，各自向本手一侧错开约 40% 半径（左圈偏左、
  右圈偏右），像两个交叠的圆，颜色各自独立，一眼能看出是哪只手的导引头在跟目标。
* 被跟踪的目标本身画一个小菱形标记，颜色取正在跟踪它的那只手的颜色。
* 目标离开圆圈立即脱锁，进度清零，圆圈恢复常态。
* 锁定过程中伴随断续提示音，完成后转为稳定音；无目标锁定失败时提示
  `NO LOCK - IR SEEKER HAS NO TARGET` / `LOCKING - HOLD SIGHTS ON TARGET`。
* 步兵与平民无法锁定（圆圈扫过也不会变成粉红）。

### 2.11 残骸

* 被击毁的步兵倒地（暗色、横躺），5 s 后消失。
* 被击毁的 APC / 机甲变成压暗的残骸并持续冒烟，10 s 后消失。
* 残骸不可锁定、不挡子弹、不算战斗单位。

### 2.12 换装面板（`B`，在基地/己方城镇 220 m 内）

覆盖全屏的半透明遮罩 + 居中大框（约 90% 视口宽、92% 高），打开时**释放鼠标锁定**，
面板里用光标点击，`ENTER` 成交、`ESC`（或 `B`、右上角 `X`）关闭。

```
┌──────────────────────────────────────────────────────────────┐
│ $100067  REARM / REPAIR                                  [X] │
│                    ┌──────────────┐                          │
│                    │ REARM SMOKE  │                          │
│                    │ $250 · 10/10 │                          │
│  L-ARM             └──────────────┘            R-ARM         │
│  ┌──────────────┐   ┌────────────┐   ┌──────────────┐        │
│  │ 30mm AUTOCANNON│  │            │   │TOP-ATTACK ...│        │
│  │ 300 RDS ·HP100%│  │            │   │ 10 RDS ·HP100%│       │
│  │ CLICK TO PICK ▾│  │   REPAIR   │   │ CLICK TO PICK ▾│      │
│  └──────────────┘   │  770 HP    │   └──────────────┘        │
│  ┌──────────────┐   │   $123     │   ┌──────────────┐        │
│  │    REARM     │   └────────────┘   │    REARM     │        │
│  │     FULL     │                    │     FULL     │        │
│  └──────────────┘                    └──────────────┘        │
│  CHANGES                                                     │
│  * R-ARM: UNGUIDED ROCKET POD (40) -> TOP-ATTACK IR ATGM  - $895 │
│  * REPAIR 770 hp                                          - $123 │
│  TOTAL: $-1018                                               │
│              ┌──────────────┐  ┌──────────────┐              │
│              │   CONFIRM    │  │    CANCEL    │              │
│              │   (ENTER)    │  │    (ESC)     │              │
│              └──────────────┘  └──────────────┘              │
└──────────────────────────────────────────────────────────────┘
```

* **武器框**：显示当前装备（或草稿里挑的那件）、总发数与该臂血量百分比。
  点一下拉出下拉列表，五项全部可购买武器，每项两行
  `名称` / `HW $本体 + RDS $弹药 = $满装`，当前装备的一项前面有 `•`、
  草稿选中项高亮；点列表项即定为该臂的新武器。
* **下拉列表是浮层**：画在面板之上、优先吃点击；点空白处收起。
* **`REARM`（每臂一个）**：补满该臂的弹匣 + 备弹，只收缺的那几发的钱。
  满弹时按钮变灰显示 `FULL`。该臂已在草稿里换了武器时这个按钮失效（换装自带满弹）。
* **`REPAIR`（中间）**：把四个模块全修到满，显示需要修多少 HP 与总价
  （从零修满整机 $400，即约 $0.16/HP）；没有损伤时变灰 `NO DAMAGE`。
* **`REARM SMOKE`（顶部）**：$250 补满 10 次烟幕并清零冷却；满库存且无冷却时变灰。
* **`CHANGES`**：草稿的每一笔一行（`* 说明 ... - $金额`，回收退钱显示 `+ $`），
  最后一行 `TOTAL: $-金额`；余额不足时 `TOTAL` 与 `NOT ENOUGH MONEY` 一起变红。
* **`CONFIRM`**：把整张草稿发给服务器，服务器**再按同一套价格重算**，够了就一次
  性执行（换装立刻生效并补满弹药）、不够就整单拒绝并弹 `SHOP DENIED - ...`。
  没有改动时 `CONFIRM` 是灰的。
* **键盘也能用**：`1`–`5` 给左臂选武器、`SHIFT`+`1`–`5` 给右臂选；`ENTER` / `ESC`
  同按钮。面板**没开**时 `1`–`5` / `SHIFT`+`1`–`5` 仍是**立即**给该臂换装（价格
  与面板完全一致），`6` 仍是立即买烟幕：快捷直购和面板两条路并存。
* 面板打开期间**不能开火、不能拉烟**，机甲可以继续走；被击毁时面板自动关闭。

### 2.13 消息（右上，逐条向下）

最多同屏 8 条，每条存活 6 s 后淡出，例如：
`+$180 KILL`（绿）、`TOWN SECURED`（绿）/ `TOWN LOST`（红）、`RE-DEPLOYED`（绿）、
`GOD MODE ON/OFF`、`MATCH RESTARTED`、`DEPLOYED AS <名字>`、`DEBUG SPAWN <类型>`、
换装成交 `DEAL DONE -$304`、拒绝 `SHOP DENIED - NOT ENOUGH MONEY`。

### 2.14 右下角状态

`FPS 60  DRAWS 214  INST 25256`（渲染统计），上方一行 `H - CONTROLS` /
`H - HIDE CONTROLS`。

### 2.15 受击与后坐反馈

* 受击时屏幕边缘红色径向渐变闪烁，强度随伤害衰减。
* 爆炸与开火产生屏幕轻微抖动（按倍率缩小，20x 下几乎不可见）。

## 3. 死亡界面

半透明暗红覆盖 + 居中三行：

```
MECH DESTROYED
RE-DEPLOY IN 7.4s
RESPAWN IS AT THE MOST ADVANCED OWNED TOWN OR THE BASE
```

相机切换为绕己方指挥部的缓慢环绕镜头，HUD 其余部分保留（可继续观察战况）。

## 4. 胜负界面

* 全屏染色（胜=墨绿，负=暗红）+ 大字 `VICTORY` / `DEFEAT`。
* 第二行 `ENEMY COMMAND BASE DESTROYED`。
* 第三行 `NEW MATCH IN 38s`（40 s 倒计时，结束后同一张地图重开）。

## 5. 帮助覆盖层（按 `H`）

画面中央 460×254 半透明面板，列出 8 行键位（移动、鼠标、滚轮、ALT、左右键、
购买、ESC）。再按 `H` 关闭。

## 6. 调试面板（仅服务端 `MECH_DEBUG=1`）

右上角 DOM 小面板，标题 `DEBUG`，三个按钮竖排：

| 按钮 | 行为 | 反馈 |
| --- | --- | --- |
| `RESPAWN` | 跳过死亡倒计时立刻重生 | 死亡界面消失，消息 `RE-DEPLOYED` |
| `RESTART` | 清场重开一局（保留地图） | 消息 `MATCH RESTARTED`，全场单位重建，玩家 3 s 后重生 |
| `GOD ON` / `GOD OFF` | 切换免伤 | 开启时按钮为绿色高亮并显示 `GOD ON` |

状态取自服务端下发（`meta.god`），刷新页面不会与实际状态不符。指针被锁定时
按钮无法点击，按 `ESC` 释放鼠标后即可操作。
