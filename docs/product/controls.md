# 按键与操作

> **读者**：玩家
> **一句话**：全部按键、鼠标动作与缩放/调零档位，一页查完。
> **数值出处**：`frontend/src/input/bindings.js`（键表）、`frontend/src/core/config.js`
> 的 `ZOOM_LEVELS`、`Core/Defs.cs` 的 `ZERO_STEPS` / `ZERO_DEFAULT`（客户端也带一份
> 同样的档位表）、`frontend/src/app/systems/settings.js`（吸附开关）
> **核对**：1.39.0 / 2026-11-20

## 1. 键位总表

| 键 / 设备 | 动作 | 说明 |
| --- | --- | --- |
| `W` `A` `S` `D` | 推动机甲 | 推杆读的是**车身**坐标系：`W` 沿车头前进，`A`/`D` 向两侧平推 |
| 鼠标移动 | 观瞄 | 转的是车顶观瞄塔，瞬时就位；车身与两臂随后追上来 |
| `ALT` + 鼠标 | 自由观察 | 视线离开准星，机甲照原样前进；松开后视角弹回观瞄线 |
| 滚轮 | 瞄具倍率 | `1x` / `4x` / `10x` / `20x` 四档，平滑过渡 |
| `CTRL` + 滚轮 | 调零距离 | `0.5` / `1` / `1.5` … `4` km，`500 m` 一档，出生时是 `1 km` |
| 左键 `LMB` | 左臂开火 | 手臂被摧毁后该扳机无效 |
| 右键 `RMB` | 右臂开火 | 同上 |
| `Q` | 热烟幕 | 一次拉烟把整排烟弹打出去，冷却与库存见告警盘下方 |
| `V` | 瞄准吸附开关 | 与设置面板里的 `AIM ASSIST` 是同一个开关，默认开 |
| `B` | 换装 / 维修面板 | 在己方指挥部或己方城镇旁边可开（靶场随处可开） |
| `ENTER` | 面板里确认 | 换装面板的 `CONFIRM` |
| `ESC` | 面板里取消 / 座舱里释放鼠标 | 释放后鼠标可以点 HUD 上的按钮 |
| `H` | 右下角提示行开关 | 在 `H - CONTROLS` 与 `H - HIDE CONTROLS` 之间切换 |

完整键位表也印在启动页上（见 [hud/lobby.md](hud/lobby.md)）。

## 2. 视角：观瞄、车身与自由观察

1. 鼠标转的是**观瞄塔**，它立刻到位；车身以固定角速度跟在后面转，两臂的俯仰也
   按自己的速率追。所以快速甩视角时中心叉先到，炮管后到。
2. 推杆的方向跟着**车身**走，转向的办法就是把观瞄指到新方向、等车身转过去。
   机甲的机动细节见 [systems/movement.md](systems/movement.md)。
3. `ALT` 只让视线离开准星：机甲保持原来的航向，松开 `ALT` 之后视角自己弹回观瞄
   线。自由观察的上下角度有限位，看不到正头顶与正脚下。
4. 倍率越高，同样的鼠标位移转过的角度越小（灵敏度按倍率缩放），高倍镜下不会一甩
   就把炮塔甩飞。

## 3. 缩放与调零

| 档位 | 值 | 用途 |
| --- | --- | --- |
| 倍率 | `1x` / `4x` / `10x` / `20x` | 滚轮切换，四格高亮在 `OPTICS` 一行 |
| 调零 | `0.5`–`4` km，`500 m` 一档 | `CTRL` + 滚轮切换，八格高亮在 `ZERO km` 一行 |

调零是"炮口按这个距离抬多少"：弹道在调零距离上与中心叉相交，比它近的目标要往下
瞄，比它远的要往上。准星、预瞄圈与落点标记怎么读见 [hud/aim.md](hud/aim.md)。

## 4. 扳机

* 左键打左臂、右键打右臂，两臂各自独立。
* 半自动武器（无制导火箭巢）一次扣扳机只出一发，按住不会连发。
* 手臂被打掉之后那一路扳机没有反应，HUD 上该臂显示 `DESTROYED` 并整体变暗。
* 需要锁定的武器在没有锁时扣扳机无效，HUD 提示 `NO LOCK`（红外弹是
  `IR SEEKER`，驾束弹是 `LASER`）。

## 5. 鼠标与面板

1. 座舱里指针是锁定的：开火与转视线都走鼠标。
2. 按 `ESC` 释放指针，画面最右上角那个齿轮（32 px 见方，距两条边各 8 px）才能点，
   点它开设置面板（音量、吸附、特效质量、调试按钮）。
3. 面板开着时鼠标归面板：武器是在下拉框里点选的，按钮也是点的。
4. `B` 打开换装面板，`ENTER` 成交，`ESC` 或 `B` 退出；设置面板是模态的，`ESC`
   或面板上的关闭按钮离开。
5. 关掉面板后点一下画面就能重新锁定指针，回到座舱。

换装面板里有什么、怎么报价，见 [hud/panels.md](hud/panels.md)。
