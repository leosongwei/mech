# 单位、体型与自卫雷达

> **读者**：调参 / 维护者
> **一句话**：战场上有哪些单位、它们各有多少血和多大个、怎么被看见和锁定、各自的赏金，以及 AI 机甲的装备是怎么抽出来的。
> **数值出处**：`Core/Defs.cs` 的 `UNIT_DEFS` / `MECH_HITSPHERES` / `AI_LOADOUTS` / `radar_strength` / `radar_k` / `CORPSE_TIME` / `WRECK_TIME`，命中球半径经 `Core/MathUtil.cs` 的 `max_radius` 汇总；数据链观察半径与锥角归 `Systems/Datalink.cs`
> **核对**：1.45.1 / 2026-11-26

## 1. 规则

一个实体是"什么"，由它在出生时拿到的**标记组件**决定，参数表只提供数据：

| 标记 | 含义（玩家能看到的后果） |
| --- | --- |
| `unit` | 弹丸会停在它身上，伤害落到它身上 |
| `combat` | 可以被瞄准，也可以占住一座城镇 |
| `lockable` | 红外导引头能锁它（机甲、装甲车） |
| `person` | 30mm 的近炸引信会在它附近起爆（步枪兵、反坦克兵、平民） |
| `moves` | 有动力，每 tick 被人/机组开动 |
| `vehicle` | 轮式：转向而不平移（装甲车） |
| `designator` | 带激光照射器，能引导 SACLOS（机甲、装甲车） |
| `datalink` | 车辆光学观察者，也携带按阵营的当前 / 最后观察状态（机甲、装甲车） |
| `invulnerable` | 弹丸停在它身上，伤害无效（靶场碉堡） |

所以"谁能被打、谁会被锁、谁会触发近炸"这三件事各有各的标记，一张排除名单都不存在。
伤害怎么算、近炸怎么触发、导弹为什么也能被打下来，都在
[damage.md](damage.md)；锁定与通道在 [../systems/seekers.md](../systems/seekers.md)。

MECH 与 APC 带 `datalink`，包括玩家、AI 与脚本傀儡；它们在 4 km、前方 ±40° 锥内进行
光学观察。步兵不带这个标签，不观察也不上报。观察对象、并集与当 tick 失效规则只在
[../systems/sight.md](../systems/sight.md) §1.7 定义。

每个单位有两个防御值：**DP 抗穿**（对抗弹药的 AP/AD）与 **DE 抗爆**（对抗 ED）。
除机甲外都只有一个血量池，`hp <= 0` 就是死；机甲的机体与左右臂各有一个池。

赏金只在击杀**敌对阵营**单位时结算，同阵营与平民都不给钱。

* **AI 交战距离（`ai_range`）与 AI 视野（`sight`）是同一个数**：视野决定它去找多远的

* **破袭机甲（raider）就是表里的机甲**：参数一字不改，出发时多挂一个 `raider` 任务
  标签，由 [../modes/battle.md](../modes/battle.md) 给它路线与任务。
* 6.5 m 是机甲从地面到机体顶的高度；速度是各车体自己的调速上限，坡上掉多少见
  [../systems/movement.md](../systems/movement.md)。

| 模块 | 索引 | 满血 | 归零后果 |

手臂血量与机体血量**各自独立**：打在手臂上只扣那条臂，手臂被打掉后落在同一位置的
伤害转进机体池，所以一条空臂不会替机体挡伤害。维修把四个池一起修满，价格与工时见
[economy.md](economy.md)。

### 2.3 命中球（车体局部坐标：右 / 上 / 前，单位 m）

命中球是**解算**的，不是采样：一条射线对每颗球求最近距离。

| 单位 | 球（右 / 高 / 前 / 半径） |
| --- | --- |
| 机甲 | 底盘 `0 / 1.45 / 0 / 1.45`、躯干 `0 / 4.15 / 0 / 1.30`、左臂 `−1.43 / 3.55 / 0.10 / 0.85`、右臂 `+1.43 / 3.55 / 0.10 / 0.85` |
| 装甲车 | 车体 `0 / 1.1 / 0 / 1.7`、炮塔 `0 / 2.4 / 0 / 1.2` |
| 指挥部 | `0 / 5.0 / 0 / 8.5` |
| 步枪兵 / 反坦克兵 / 平民 | `0 / 0.9 / 0 / 0.65` |
| 碉堡 | `0 / 4.0 / 0 / 5.0` 与 `0 / 8.8 / 0 / 3.6` |
| 残骸 / 尸体 | `0 / 1.0 / 0 / 1.5`（惰性，不参与判定） |

一个单位"身体多大"取的是**最大那颗球**的半径（`max_radius`），AI 扣扳机的角径门用它：

| 单位 | 最大球半径 | 说明 |
| --- | --- | --- |
| 步枪兵 / 反坦克兵 / 平民 | 0.65 m | |
| 机甲 | 1.45 m | 底盘那颗 |
| 装甲车 | 1.70 m | 车体那颗，比炮塔那颗大 |
| 指挥部 | 8.50 m | |
| 碉堡 | 5.00 m | |

碰撞半径（2.1 表里那一列）是"车会撞到什么"，与命中球是两件事：碰撞圆是 2.2 m 的
装甲车，挨弹的身体是 1.7 m 的球。

### 2.4 自卫雷达（`radar_strength`）

机甲与装甲车各带一部自卫雷达，它只做两件事：给驾驶员报来袭弹，让 AI 机组发现来袭的
火箭与导弹。判据是**多普勒**的一条式子（`Defs.radar_k`）：

```
radar_strength · rcs / d⁴ · (v_c / v_ref)² >= 1
  ⟺  d² <= K · v_c,     K = √(radar_strength · rcs) / v_ref
```

`v_ref` 是 600 m/s（`RADAR_V_REF`，游戏里持续速度最快的一档），它只把速度那一项
变成无量纲；`rcs` 是弹丸的雷达反射截面，`v_c` 是**接近速度**。所以一个平台看见多远
由"弹有多亮、来得多快"决定，平台只有一个旋钮 `radar_strength`（m⁴）。

| 平台 | `radar_strength` | 对 SACLOS 的解算距离 | 对 SACLOS 的听见距离 |
| --- | --- | --- | --- |
| 机甲 | 1.75e14 | **1368 m** | **2728 m**（上限常数） |
| 装甲车 | 3.125e12 | **500 m** | **997 m** |
| 步兵 / 平民 / 指挥部 / 碉堡 / 残骸 | 0（没有雷达） | — | — |

各弹种按**自己到达时的速度**算出来的距离：

| 弹种 | `rcs` m² | 到达速度 m/s | 机甲解算 | 机甲听见 | 装甲车解算 | 装甲车听见 |
| --- | --- | --- | --- | --- | --- | --- |
| SACLOS / APC ATGM | 0.02 | 600 | 1368 m | 2728 m | 500 m | 997 m |
| S-8 火箭（HEAT / HE 两种战斗部） | 0.005 | 610 | 975 m | 1946 m | 357 m | 711 m |
| 攻顶红外弹 | 0.02 | 306 | 977 m | 1949 m | 357 m | 713 m |
| RPG | 0.002 | 300 | 544 m | 1085 m | 199 m | 397 m |

* **两个门限差 12 dB**（`ALARM_DB`）：告警只做一次判决，所以"听见"距离是"解算"距离的
  `10^(12/20) = 3.98` 倍作用在 `d²` 上，即 **1.995 倍**。圆盘上因此有三个层次：只有
  方位、有位置、有判定——判据链在 [../systems/rwr.md](../systems/rwr.md) 里。
* **上限常数 2728 m** 出现在 `v_c` 被封顶在 `v_ref` 那一刻，也就是最快的那一档弹；
  这个数永远落在告警盘的 3 km 盘面以内。
* 强度差 **56 倍**，距离是它的四次方根，所以装甲车只看得到机甲的 **1/2.7**：同一枚
  SACLOS，机甲在 1368 m 就解算出位置，装甲车要等它到 500 m。
* 机甲这一档是**攻顶弹定的**：一次 2.2 km 的发射在命中前 4 s 时距车 778 m、接近
  速度 195 m/s，解算要求 `K ≥ 778²/195 = 3100`，即 `radar_strength ≥ 1.73e14`，
  取整为 1.75e14。那 4 s 正是把 30mm 压进引信锥并开火的时间。
* 把 `radar_strength` 改成 0 就是彻底的瞎子：告警器与 AI 的拦截都读它，没有第二处。

### 2.5 AI 装备模板抽签

AI 机组没有钱、不会去换装，所以出生时**按概率抽一套配置**（`defs.AI_LOADOUTS`）：

| 概率 | 左臂 | 右臂 |
| --- | --- | --- |
| **20%** | 30mm AUTOCANNON | UNGUIDED ROCKET POD（HEAT） |
| **10%** | 30mm AUTOCANNON | LOITERING MUNITION |
| **10%** | 30mm AUTOCANNON | 30mm AUTOCANNON（双炮） |
| **20%** | 30mm AUTOCANNON | SACLOS ATGM |
| **15%** | 30mm AUTOCANNON | TOP-ATTACK IR ATGM |
| **15%** | 30mm AUTOCANNON | 105mm SMOOTH BORE |
| **10%** | 30mm AUTOCANNON | 12.7mm MACHINE GUN |

* **左臂恒为 30mm**，所以每一台 AI 机甲都有一条**带引信**的手臂——诱饵、拦截都靠它，
  见 [../systems/ai.md](../systems/ai.md)。
* 抽签发生在 `World.spawn_unit` 给一台**双臂车体**装武器的时刻，条件是这次出生没有
  显式指定 `weapons`。于是：指挥部的机甲、前线增援、破袭机甲与 `debug_spawn` 放出来
  的 AI 机甲都抽签；**玩家**的机甲永远用 `DEFAULT_LOADOUT`（30mm 机炮 + 无制导火箭巢）；
  靶场的导弹防御哨位自带一份 `LOADOUT` 也不抽。
* 能拆重甲的四档（SACLOS 20 + 攻顶 15 + 105mm 15 + 游荡弹药 10）合计 **60 %**。游荡弹药
  那一档原来是高爆火箭巢：车道上机组打的是车，一台机组上空盘旋的无人机比第二个战斗部
  更有用。高爆火箭巢因此**不再出现在 AI 的配装表里**，玩家仍可在换装面板买到。
* 抽签只决定右臂；两门 30mm 的机甲射速翻倍，而主臂规则会让其中一门始终站着不开火，
  见 [../systems/firecontrol.md](../systems/firecontrol.md)。

### 2.6 残骸与尸体

被击毁的单位留下一个**惰性实体**：没有 `unit` 标记，于是不参与索敌、挨不到弹、挡不住
弹道、也不被占领判定看见；它只是画出来的东西，倒计时到点由 `Debris` 删掉。

| 被击毁的单位 | 残骸 | 外观 | 存在时间 |
| --- | --- | --- | --- |
| 步枪兵 / 反坦克兵 / 平民 | 尸体（id 8） | 倒地，阵营色变暗 | **5 s**（`CORPSE_TIME`） |
| 装甲车 | 车体残骸（id 7） | 压扁变黑，阵营色蒙尘 | **10 s**（`WRECK_TIME`） |
| 机甲 | 机体残骸（id 7） | 塌在腿上，持续冒烟 | **10 s** |

* 残骸在快照里靠 `flags` 的 **bits 4–5** 携带自己的样子（`wreck_kind`：1 = 装甲车，
  2 = 机甲，0 = 不是残骸），客户端据此选模型；车辆与机甲残骸每 0.12–0.20 s 冒一团烟。
* 死车那次自爆发生在残骸落地**之前**，而残骸已经不是单位，所以自己那一炸不会落到
  自己身上。自爆的范围与伤害归 [damage.md](damage.md)。

## 3. 判定与边界

* **谁能被锁定**：只有带 `lockable` 的机甲与装甲车。指挥部、碉堡、残骸、步兵都锁不上，
  所以攻顶弹与 SACLOS 在它们身上只有一个结果——打不出去。`datalink` 是观察者资格，
  `lockable` 是武器目标资格，两者不互相替代。
* **谁会触发近炸**：带 `person` 的三个步兵类单位；此外**空中的火箭 / 导弹**也会，
  因为一枚制导弹自己就是一颗 10 点血的小目标，见 [damage.md](damage.md)。
* **角径门**：AI 扣扳机要求炮口方位误差小于 `atan((最大球半径 + 弹丸半径) / 距离)`，
  1 km 上对机甲约 0.08°，对步兵约 0.04°。这条门与俯仰门属于火控，见
  [../systems/firecontrol.md](../systems/firecontrol.md)。
* **视野是三维斜距**：机组量的是眼点到目标车身几何中心，与火控解算、视线判定用的是
  同一个量，所以山脊上的目标不会出现"看得见却永远不开火"。
* **爬坡上限按底盘**：装甲车 0.58、机甲 0.70、步兵 0.80（升 / 水平距），归
  [../systems/movement.md](../systems/movement.md)；它同时是导航网格的判据。
* **伤害读的是自己那一小段时刻的血量**：一颗子弹命中的是它飞到的那个 tick 的 `hp`，
  0 血的车在被判死之前仍在场上一小会儿，所以一帧之内两个来源可以打死同一台车。

## 4. 设计与取舍

* **步兵 10 血是刻意的临界**：一发 12.7mm 弹（AD 10 > DP 1）当场打死，而 5.56mm 步枪
  （AD 4）正好要三发，两发只有 8 点。于是步兵对装甲毫无威胁，人打人才打得起来。
* **机甲 120 血、手臂 50 血是分开定的**：手臂是机体的 42 %，打掉一条臂要一整梭而不是
  一发，这是"拆零件"这个玩法存在的前提。
* **装甲车只有一个血池**：炮塔只是第二颗命中球，血量不分区，所以打断炮塔这种打法**不存在**，
  打车的每一发都算在同一个 100 点上。
* **雷达只有一个参数**：距离对 `radar_strength` 是四次方根，所以"看见多远"是一个可以
  单独调的档位，与告警器的代码解耦；想削弱载具的预警就改这个数，判据不用碰。
* **AI 的装备由抽签决定**：机组没有经济系统，抽签让战场上出现不同配置，同时把所有
  AI 机甲的左臂统一成 30mm，保证每一台都还有反导能力。
* **残骸是"没有身份的实体"**：它不靠排除名单活着，而是出生时就不带 `unit`。所以
  新增一种残骸不需要去五个系统里加一行 `if`。
