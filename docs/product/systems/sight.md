# 视线：唯一的一道门

> **读者**：机制维护者
> **一句话**：从 A 到 B 这条线段上有什么挡着——地面、建筑到屋顶、树干与树冠、烟球、别的车体——以及为什么机组、红外锁定、导引头、告警器和预瞄框问的都是同一个函数。
> **数值出处**：`Systems/Sight.cs`（`LOS_STEP` / `clear` / `why`）、`Core/Terrain.cs`（`los` / `_march` / `_canopies` / `_trunk_hit`）、`Systems/Smoke.cs`（`blocks`）、`Systems/Beams.cs`（`painting` / `_body_hit`）、`Core/Defs.cs`（`SMOKE_FLAT` / `LASER_SPHERE` / `LASER_RANGE` / `BEAM_*`）；客户端镜像在 `frontend/src/map/sight.js`
> **核对**：1.39.0 / 2026-11-20

## 1. 规则

### 1.1 一个问题，两个答案

看得见看不见，在服务器上只有一个函数：`Sight.clear(a, b)` 回答"通"或"不通"，
`Sight.why(a, b)` 回答同一件事加上原因——空串（通）、`"smoke"`、`"terrain"`。原因只有
一个读者：导引头丢掉锁时写进日志的那一行（靶场的烟幕测试读它）。

答案是两半拼起来的，顺序固定：**先问烟，再问地形**。烟是近处、临时的那一半，地形是
永久的那一半；一串挡在中间的烟球就足够叫一条线断掉，不必再往山下走。

### 1.2 静态场：地面、建筑屋顶、树冠

地形那一半（`Terrain.los`）沿线段每 **8 m** 取一个采样点（半格，16 m 的建筑不可能从两
个点之间溜过去），问三件事：

* **地面**：这个点在地面以下吗（连续高度场，`height_at` 的三角面，见
  [../rules/map.md](../rules/map.md)）；
* **建筑**：这一点落在哪一格、那一格有没有房子、点在屋顶以下吗（整格柱体，从地面长到
  `walls` 给的楼层高度）。房子挡到屋顶为止，所以山脊上的观察哨能越过一排矮房。
* **树冠**：这一点在某棵树的树冠体里吗（§1.3）。

### 1.3 树干实心，树冠遮眼

一棵树分开算两次，因为它们挡的不是同一种东西：

| 部位 | 形状 | 挡什么 |
| --- | --- | --- |
| 树干 | 竖直圆柱，半径 0.35–0.6 m，高约全树的 40 % | 弹丸与车体：一条弹道撞上树干就停，一台车开不进树里，但能从树冠底下开过去 |
| 树冠 | 阔叶是一个球（椭球，长在树干上），针叶是一个立着的圆锥 | 只挡眼睛，与烟同一档 |

两种树冠**各自解算**、从不采样：一颗球几米宽，8 m 一步必然从它的边上跨过去。阔叶与
针叶由同一组哈希抽样决定（`q3 > 0.45` 是阔叶），客户端用同一组数画模型，所以"HUD 说
这里看不见、真就看不见"是同一个体。

一条随之而来的规则：**一棵树从来不让一整格实心**。旧实现把树当成盖住整格 16 m 的 10 m
板子，于是站在树丛边上、明明在空地上的车体也被判成看不见。现在只有树干是实体、只有
树冠是遮挡，站在两棵之间就是站在空地上。

### 1.4 烟幕是一实体，不是一块地形

一炮热烟幕扔出去 14 个罐子，每个落地起爆成一个烟球；投出去的姿势、抛距、抖动、生长
曲线与存活时间归 [../rules/weapons.md](../rules/weapons.md) §2.4，这里只说它对
视线意味着什么：

* 挡视线的是**已经起爆的烟球**，还在飞的罐子只是普通实体；
* 判定是**线段与椭球求交**，用这一帧的真实半径（起爆约 1 s 长到九成），所以一个刚炸开
  的烟球挡得比半秒后少；
* 一次拉烟关掉整个前半球，被挡住的既有别人的红外锁，也有别人告警器上对这一发的方位线，
  还有别人的激光（§1.5）。

### 1.5 激光是光：判定球

一台机甲或装甲车随时在发五束激光：**观瞄那一条线本身就烧着**（不按键也发），外加它的
计算机替它导引的**四通道**激光。接收机的问题只有一个，五束一起问：**这束光有没有照在
我身上？**

判定是几何的，不是角度的：每台车有一个**判定球**，球心在车体几何中心，半径
**`LASER_SPHERE` = 10 m**，射线够到球就算照上了。10 m 比车体宽得多，因为指示器是灯
不是针：光源有孔径、光斑随距离铺开、接收器又有门限，从车顶十来米外擦过去的光在接收机
眼里仍然照着自己——而警告本来就该在弹到之前听见。

挡住它的东西和挡住眼睛的是同一套（§1.1），外加**别的车体**：射线最先撞上的那台车就是
光的尽头。射线总长 `LASER_RANGE`（4 km，与驾束弹的锁距同值）。

判定在服务端（`Beams.painting`），客户端只把答案画成三角形：每台 10 Hz 的 `meta` 带
`lasers` 一列，一台车一条，不管它有几条线照在你身上。

### 1.6 谁在走这道门

| 眼睛 | 用途 |
| --- | --- |
| 机组瞭望（`Systems/AI/Sense.cs`） | 能不能看见那个目标；被挡住就按记忆点打 2 s，见 [ai.md](ai.md) |
| 玩家红外锁与导引头 | 能不能锁、锁住之后记不记得，见 [seekers.md](seekers.md) |
| 驾束弹的激光 | 激光还够不够得着这一发弹（一道山脊就切得断），见 [flight.md](flight.md) |
| 告警器 | 手里这一发到底有没有被看见，见 [rwr.md](rwr.md) |
| 预瞄框 | 只画在真能锁的车体上（客户端 `sightBlocked`），见 [../hud/aim.md](../hud/aim.md) |
| 激光告警 | 上面那一束光有没有照在判定球上 |

**弹道预测走的是另一套。** 客户端算落点与提前量用的是弹丸自己的规则：挡它的是地面、
屋顶和树干。两套规则各有各的函数，唯一的约定是两端一份不差（见 [firecontrol.md](firecontrol.md)）。

## 2. 数值表

| 常数 | 值 | 含义 |
| --- | --- | --- |
| `LOS_STEP` | 8 m | 视线每步的采样间距（半格）；地形与建筑按它走，树冠与树干按它求交 |
| 树高 | 10–18 m | 每棵树自己的抽样值，决定冠幅与树干高 |
| 树干 | `r` 0.35–0.6 m，`h` ≈ 全树 40 % | 车体与弹丸的实体 |
| 阔叶冠 | 球，半径 ≈ 全树 40 % ×(0.85–1.15)，中心在半高处 | 遮挡体 |
| 针叶冠 | 立锥，从 15 % 到 95 % 树高处，底半径 ≈ 全树 26 % ×(0.85–1.15) | 遮挡体 |
| `SMOKE_FLAT` | 45 m（水平与垂直同值） | 一个烟球的半径；判定就是线段 vs 这个椭球 |
| `LASER_SPHERE` | 10 m | 判定球半径：光斑发散加接收机门限，不是车宽 |
| `LASER_RANGE` | 4000 m | 一束光还算数的长度，与 SACLOS 的锁距同值 |

## 3. 判定与边界

* **烟先于地形**：一条线同时被两者挡住时，`why` 报 `"smoke"`。导引头日志里那一行因此
  能读出"被烟挡住"，烟幕测试靠的就是它。
* **树冠是体，不是格子**：判定用真实的球与锥，落在哪一格只决定去哪个列表里找；树冠可以
  伸进隔壁格，客户端画的和服务器解的是同一个体。
* **通道激光与观瞄激光分开读**：通道在被挡住之后仍按记忆导引（`beam_ok`），但那段时
  间光没有打在别人身上（`beam_lit` 是 0）——于是那边"锁还在"、这边"告警器静音"，两件事
  分开上报。
* **带指示器的才是激光源**：机甲与装甲车有 `designator`；步枪兵、反坦克兵、平民、指挥部、
  碉堡、残骸都没有，一串步枪瞄过来不会让激光告警响。
* **客户端同一套规则**：`map/sight.js` 的 `sightAt` / `canopyOf` / `sightBlocked` 是本页
  服务端版本的逐行镜像（两种树冠、烟球、地面与屋顶），因为 HUD 只该在真能锁的车体上画框。

## 4. 设计与取舍

* **一条门是为了让"看不见"只有一个答案。** 玩家的红外锁一度只问静态场，于是隔着一整片
  烟也能锁，锁框立在一台导弹已经看不见的车体上。把眼睛收到一个函数之后，加一种新的遮挡
  （烟）就是加在一个人身上，不必去改五个调用点。
* **树干实心、树冠透明是两条规则，各自服务一种东西**：物理要的是"开得过去、打得到"，
  视线要的是"看不看得见"。合成一条（整格板）会让空地上的车体隐身。
* **激光用球不用角**：角度表达不了"光从十米上空擦过去"。通道激光最多偏开视线 40°，
  所以看不见的那一发才是会告警的那一发——这只有几何判定说得出来。
* **烟球的判定跟着尺寸走**：一炸就开始挡，长满之前挡得少一点。刚拉烟的那一帧就藏得住、
  烟快散了还挡着，两种边界都成立，不必为生长期单开参数。

## 5. 实测

* 靶场（`./dev.sh range`）的烟幕 A/B 测试读的是 `why` 的原因：一发攻顶弹在一泡烟后面丢
  掉锁，日志写 `smoke`；同一发弹被山脊挡住写 `terrain`。读数见 [rwr.md](rwr.md) 附录 B
  与 [seekers.md](seekers.md)。
* 激光告警的全部情形由 `./dotnet.sh run -- --check beam` 的 `paint` 行一次走完：观瞄压在
  车身上、偏开一个车身、锁着而准星偏 25°、烟幕、中间停一台车、视线转出 40° 锥。
* 客户端与服务端的一致性靠同一组树哈希保证（两边各算一次树冠），只有一份地图。
